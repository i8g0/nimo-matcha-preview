# نيمو ماتشا — ثيم سلة

ثيم جديد كليًا لمتجر نيمو ماتشا، مكتوب بنظام سلة الرسمي **Twilight** (Twig + CSS + JavaScript). معه معاينة تحاكي سلة وتعمل على Vercel، حتى يشوف المالك الموقع ويوافق قبل أي تغيير على المتجر.

> **لم يُطبَّق أي شيء على المتجر الحالي.** المعاينة مستقلة، والتركيب في سلة يكون على نسخة ثيم منفصلة بعد موافقة المالك.

```
theme/     ← الثيم نفسه، هذا اللي ينتقل لسلة
preview/   ← محاكي سلة للمعاينة فقط (لا يُنقل) + بيانات نيمو الحقيقية
tools/     ← مولّد twilight.json (أقسام الرئيسية وإعدادات الثيم)
```

## التشغيل محليًا

```bash
npm install
npm run dev      # يبني ويفتح http://localhost:5500 ويعيد البناء مع كل تعديل
npm run build    # يبني نسخة Vercel في dist/
```

## النشر على Vercel

`vercel.json` يحدد أمر البناء (`npm run build`) ومجلد الإخراج (`dist`). من vercel.com/new اختر المستودع واضغط Deploy، أو نفّذ `vercel` من المجلد.

في المعاينة: السلة محفوظة في المتصفح، كود الخصم التجريبي `NIMO10`، وزر «إتمام الطلب» يعرض رسالة بدل صفحة الدفع.

## أقسام الصفحة الرئيسية (كلها تُدار من محرر الثيم في سلة)

| المكوّن | ماذا يفعل |
|---|---|
| البنر الرئيسي (شرائح) | صورة أو فيديو داخل شكل نيمو العضوي، لون لكل شريحة، زرّان، ملصق عرض، شارة التقييم |
| دوائر التصنيفات | اختصارات للأقسام |
| شريط المزايا | ٤ أسباب ثقة بأيقونات |
| المنتج الأكثر طلبًا + عداد العرض | منتج واحد ومحتوياته وعداد ينتهي في تاريخ تحدده (يختفي تلقائيًا بعده) |
| المتجر (منتجات مع تبويبات) | التبويبات تتكوّن من تصنيفات المنتجات المختارة |
| مختار النكهات التفاعلي | الضغط على النكهة يغيّر اللون والصورة والمنتج |
| طريقة التحضير بخطوات | أرقام كبيرة (٢ جم، ٨٠°…) + صورة أو فيديو |
| كمّل كوبك (اشترِ معًا) | العميل يختار ويضيف الكل بضغطة، ويشوف كم وفّر |
| شريط منتجات أفقي | يُستخدم أكثر من مرة لأي مجموعة |
| بنر صورة (كمبيوتر وجوال) | لبنرات العروض الجاهزة، بدون قص |
| لحظات نيمو | معرض صور متحرك + زر إنستقرام |
| آراء العملاء | تقييم عام + آراء حقيقية (علامة «مشتري موثّق» اختيارية لكل رأي) |
| قصة نيمو، الأسئلة الشائعة، دعوة للتواصل | |

### إعدادات الثيم
الشريط العلوي (٣ رسائل)، شريط الأقسام، الشريط السفلي في الجوال، «سعر الكوب» وجرامات الكوب، منتجات «كمّل كوبك» داخل السلة، النغمة عند الإضافة، نبذة الفوتر، وسائل الدفع، رابط واتساب.

### ما يُضبط من لوحة سلة (بدون كود)
| الميزة | من أين |
|---|---|
| روابط الهيدر وأزرار الأقسام والفوتر | المتجر ← القوائم (قائمة الهيدر وقائمة الفوتر) |
| شارة على كرت المنتج («الأكثر طلبًا») | حقل **عنوان العرض الترويجي** في المنتج |
| شارة الخصم ٪ | تلقائيًا من السعر قبل وبعد الخصم |
| «يكفي ~٤٠ كوب · ٢٫٢ ر.س للكوب» | تلقائيًا من الوزن في اسم المنتج (`80 جرام`، `1كيلو`) |
| الشعار والخط | المتجر ← الهوية |

## النقل إلى سلة (بعد موافقة المالك)

`theme/` ثيم سلة كامل مبني على ثيم **رائد** الرسمي: صفحات رائد الأخرى (حساب العميل، الطلبات، المدونة، الماركات، صفحة الشكر…) موجودة وتعمل، والصفحات المصمّمة (الرئيسية، المنتج، التصنيف، السلة) والهيدر والفوتر هي تصميم نيمو.

| الملف | الدور |
|---|---|
| `twilight.json` | أقسام وإعدادات نيمو أولًا، ثم إعدادات رائد (يُولَّد بـ `node tools/twilight.mjs`) |
| `src/assets/styles/nm.css` | نظام التصميم: الألوان والخطوط والمسافات كلها متغيرات في `:root` |
| `src/assets/js/nm-*.js` و `src/assets/js/nm/` | الحركة والسلة والصفحات |
| `src/assets/js/nm/store.js` | **الملف الوحيد اللي يكلّم سلة** (`salla.cart.*`). أي تغيير من سلة يُصلح هنا فقط |
| `src/views/components/home/nm-*.twig` | قسم لكل ملف |

**الخطوات:**
1. `npm i -g @salla.sa/cli` ثم `salla login` (حساب شركاء سلة).
2. انشر مجلد `theme/` كمستودع مستقل (سلة تربط كل ثيم بمستودع `twilight.json` في جذره).
3. من داخل المجلد: `npx pnpm@10 install` ثم `salla theme preview` على متجر تجريبي.
4. اختبار الشراء كامل (أدناه)، ثم `salla theme publish` وتفعيله في المتجر. الثيم القديم يبقى متاحًا للرجوع.
5. من محرر الثيم: رتّب الأقسام، ارفع الصور، واختر المنتجات.

### نقاط تحقق عند أول تركيب على المتجر التجريبي
- الإضافة للسلة من الكرت وصفحة المنتج، وتغيير الكمية والحذف من السلة الجانبية وصفحة السلة.
- شكل استجابة `salla.cart.details()` (الملف يقرأ `product_name` و `product_image` وله بدائل).
- منتج بخيارات (حجم/نكهة): يستخدم فورم سلة الرسمي `salla-add-product-button`.
- كود الخصم `salla.cart.addCoupon` ورسالة الخطأ.
- اقتراحات «كمّل كوبك» تجلب المنتج بـ `salla.product.getDetails`، وإن لم يتوفر يختفي القسم بهدوء.
- `<salla-products-list product-card-component="nm-product-card">` يرسم كرت نيمو في صفحات التصنيف والبحث.
- الجوال (iPhone وAndroid) والكمبيوتر، والوضع بدون حركة.
